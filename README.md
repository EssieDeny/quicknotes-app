# QuickNotes 📝

QuickNotes is a simple, responsive note-taking web application built with HTML, CSS, and JavaScript. It helps users organise their thoughts, manage important information, and keep track of notes in one place.

## Features

- Add notes with a text description.
- Organise notes into Personal, Work, and Study categories.
- Search notes by their text, regardless of letter case.
- Delete notes when they are no longer needed.
- Automatically save notes in the browser using localStorage.
- Display the total number of saved notes.
- Validate note input and display helpful error messages.
- View notes with their category and creation date.
- Use the application on desktop and mobile screens with a responsive layout.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser localStorage
- Git and GitHub

## How to Run

1. Clone or download this repository from GitHub.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` using the Live Server extension.
4. Add, search, categorise, and delete notes in your browser.

## Note on Data Storage

QuickNotes stores notes locally in the browser using `localStorage`. Notes remain available after refreshing the page in the same browser and origin. However, they are not automatically synchronised across different browsers or devices.
