# QuickNotes 📝

QuickNotes is a simple, responsive note-taking web application built with HTML, CSS, and JavaScript. It helps users organise their thoughts and keep track of important information.

## Features

- Add notes with a text description.
- Organise notes into Personal, Work, and Study categories.
- Search notes by their text or category.
- Delete notes when they are no longer needed.
- Automatically save notes in the browser using localStorage.
- Display the total number of saved notes.
- Validate note input and show helpful error messages.
- Responsive layout for desktop and mobile screens.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser localStorage

## How to Run

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` using the Live Server extension.
4. Add, search, and manage your notes in the browser.

## Note on Data Storage

Notes are stored locally in the browser. They remain available after refreshing the page, but they are not automatically synchronised across browsers or devices.
